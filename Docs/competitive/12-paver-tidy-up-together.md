## Premise & scope — the first non-shelf variant

First-person organizing game about sorting and placing **pavers to rebuild a plaza** — 4,064
pavers total, in different colors and shapes (rectangle, square, octagon, trapezoid, H-shape,
triangle, hexagon, trihex, radial). Solo or online co-op.

## Mechanics

- Same skeleton as the shelving games (place items in correct destinations, unlock skills,
  Sandbox/No-Skill modes) but the destination is a floor-pattern layout, not a shelf — a rare
  format variation in an otherwise nearly-identical set of mechanics.

## Relevance to BookBoy

- Confirms the underlying "correct-destination placement" loop generalizes well beyond
  shelves/stores — useful validation that BookBoy's core interaction (identify → carry → place
  correctly → feel good) isn't tied to the shelf format specifically, which supports the brief's
  view that the *loop*, not the *setting*, is the reusable asset.
